## 一句话定位

面向中医经典课程学习者的自测工具：**只依据已导入典籍，每处结论都能回到原文**。不做诊断、处方、剂量建议。

## 系统流程

**学习者端**

1. 微信登录 → 账号绑定，小程序与 PC 同账号。
2. 选书／篇 → 阅读：按底本段落顺序呈现，书名、篇名、条号、原文片段常驻。
3. 检索：条文、方名、药味、医案四入口；结果按类型分组，每条可回溯。
4. 练习：选范围与题型 → 出题 → 作答 → 判分并展示依据 → 错题进复习。
5. 提问：命中给原文与出处；未命中拒答并记缺口；模型默认关闭。
6. 收藏、笔记、阅读进度跨端同步。

**管理员端**

1. 书目申请审核：缺目录或缺版本不得通过，驳回留理由。
2. 导入：解析 → 切分 → 去重／清洗碎片 → 建章节树 → 性质标注 → 抽方药 → 归一与碰撞检查 → 质检门禁 → 入库。
3. 校对：逐条确认或修正，修正留痕。
4. 治理：缺口与冲突队列，并列展示，不裁决内容对错。
5. 审计：登录、导入、修正、删除可查；越权访问被拒。

## 主要功能设计

| 功能 | 关键设计 | 为什么这样定 |
|---|---|---|
| 阅读 | 显示值照底本不改写；归一值只用于检索、不上界面；出处块统一结构 | 改写正文等于毁底本（BR-03）；出处缺书名或篇名不得输出（BR-01） |
| 检索 | 实体走归一值等值；段落走 `norm_text` 子串＋`pg_trgm` GIN＋`LIKE`；不建 `search_tsv` | 实测分词漏检 6.3%～12.8%；子串匹配零漏检 |
| 练习 | 只做组成匹配、类方比较、选择题；题目由判据装配；唯一正解校验；选项 id 判分，无部分分 | 自由文本判不准会把对的判错；BR-08 只允许确定性判分 |
| 提问与拒答 | 按 R1～R7 短路；无出处不输出；未命中写缺口；模型默认关闭 | 无专家审核，唯一可信来源是原文；拒答是功能不是故障 |
| 治理 | 冲突只并列、不设“胜出值”；缺口三态；审计只增不改 | 系统不替专家裁决（BR-07）；处理轨迹可复核 |
| 数据 | 30 张表、37 条显式索引、38 个外键（7 个级联）；一表一主写者 | 内容与审计永不删除；级联只用于删账号与作废题 |

## 技术点

| 点 | 结论 |
|---|---|
| 架构 | 模块化单体＋独立导入 Worker＋单库；导入失败整批回滚（NFR-20） |
| 不引入 | 消息队列、Elasticsearch、zhparser；理由是规模与运维成本，不是技术偏好 |
| 内容模型 | 书 → 章 → 内容单元；显示值／归一值两份；原典归属可空；判据完整标记 |
| 导入 | 规则只预填，人工标注为主；去重 1638 段、78 表里 76 个是目录行表 |
| 出题 | 题干、选项、正解全部由结构化判据确定性装配；`fingerprint` 防重复；源头修正即失效 |
| 接口 | 48 项端点、51 个方法；错误码与字段在 `05` §10.3 冻结 |
