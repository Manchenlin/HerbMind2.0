# 阶段 0 + M1：地基与数据底座 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 让三名成员各自本地跑通「前端页 → BFF → 样例服务 → PostgreSQL」一条端到端链路，且数据一致（语料、向量、图谱由脚本产出）。

**架构：** 先落地 `docker-compose.infra.yml`（PG17+pgvector+pg_jieba / Neo4j5 / Redis7 / Nacos2）与 `database/pg` DDL；再用 ETL 脚本灌入极小种子；随后建立 `herbmind-common` / `herbmind-contract` / 样例服务 `svc-catalog` / `herbmind-gateway` / `herbmind-bff` 骨架，打通一条 `/api/biz/library/tree` 链路；前端 Vite 工程对接该链路；最后 Neo4j 最小建图 + 冒烟脚本。

**技术栈：** Java 17 + Spring Boot 3 + Spring Cloud Gateway + OpenFeign + MyBatis-Plus；PostgreSQL 17（pgvector/pg_jieba/pg_trgm）+ Neo4j 5 + Redis 7 + Nacos 2；Vue 3 + TS + Vite + Pinia + Element Plus；Python 3.11（ETL 脚本）。

**规格：** `project_plan/15_团队分工与接口协作.md`、`project_plan/09_API契约清单.md`（§0 规范、§13 打样）、`project_plan/06_数据库设计_PostgreSQL.md`、`project_plan/05_系统技术架构.md`

## 全局约束

- 分工：**纵向域切 · 人人全栈** —— **域1 内容域 = A（原纯前端）**、**域2 成长域 = B**、**域3 智能域 = C**；每人负责自己域的**后端 + 前端**。本计划（阶段 0 + M1）由**三人合力**，其中"内容侧"任务主要由**域1（A）**落地。
- 路由分层（方案 A）：`/api/biz/**` **仅 BFF**；`/api/agent/**` **仅 Agent**；各 svc **只暴露 `/internal/**`**。
- 响应外壳 `R<T> = {code, msg, data}`；分页 `PageResult<T> = {list, total, page, size}`。
- **JSON 字段 camelCase；数据库列 snake_case**。
- 时间用 ISO 8601 字符串；ID 用字符串（`"n_1"`），不用自增数字。
- 鉴权头 `Authorization: Bearer <token>`；白名单：`/api/biz/user/login`、`/api/biz/user/register`、`/api/agent/health`。
- **PG 生成列 `search_tsv` 禁止被 ORM 映射**（插入会报错）。
- 时间列用 `TIMESTAMPTZ`，Java 侧映射 `OffsetDateTime`（**不要用 `LocalDateTime`**）。
- 语料目录**唯一表 `book_node`**（自引用树）；**不存在** `book_chapter/section/category`。
- 检索入口**唯一表 `content_unit`**（向量 + 全文）；`svc-search` / Agent **只读**，由 ETL 写入。
- 本增量**不引入消息队列**；索引/图谱靠 ETL 定时或手动重建。
- Git：`main` 保护；每人 feature 分支 → PR；契约文件（`09`）改动需 3 人 review。

## 审查重点（Review Focus）

1. **pg_jieba 未装/未建索引** → 中文检索全空。期望：装扩展 + 建 GIN 索引，`plainto_tsquery('jiebacfg', q)` 能命中。
2. **时区偏移**：用 `LocalDateTime` 接 `TIMESTAMPTZ` → 时间错 8 小时。期望：`OffsetDateTime` 往返一致。
3. **camelCase/snake_case 不一致** → 前端拿到 `undefined`。期望：JSON 输出 camelCase（`nodeType` 而非 `node_type`）。
4. **生成列被映射** → 插入报错。期望：`search_tsv` 不在实体字段里。
5. **空子节点** → 前端渲染崩溃。期望：无子节点时 `children` 返回 `[]`（非 `null`）。

  id TEXT PRIMARY KEY, title TEXT NOT NULL,
  book_type TEXT NOT NULL CHECK (book_type IN ('fz','bencao','drug','case')),
  author TEXT, dynasty TEXT, source_license TEXT, ingest_status TEXT DEFAULT 'draft');
CREATE TABLE book_node (
  id TEXT PRIMARY KEY, book_id TEXT NOT NULL REFERENCES book(id),
  classic_id TEXT, parent_id TEXT REFERENCES book_node(id),
  node_type TEXT NOT NULL CHECK (node_type IN ('chapter','section','category','unit')),

- [ ] **步骤 2：写内容域 + 统一内容单元**

CREATE TABLE classic (id TEXT PRIMARY KEY, book_id TEXT REFERENCES book(id), name TEXT, abbr TEXT, dynasty TEXT);
CREATE TABLE formula (id TEXT PRIMARY KEY, name TEXT NOT NULL, node_id TEXT REFERENCES book_node(id),
  efficacy TEXT, syndrome_text TEXT, page TEXT);
CREATE TABLE formula_herb (id SERIAL PRIMARY KEY, formula_id TEXT REFERENCES formula(id), herb_name TEXT, dose NUMERIC, unit TEXT, role TEXT, seq INT);
CREATE TABLE classic_quote (id TEXT PRIMARY KEY, article_no TEXT, classic_id TEXT REFERENCES classic(id), content TEXT, page TEXT);
CREATE TABLE content_unit (
  id TEXT PRIMARY KEY, book_id TEXT REFERENCES book(id), unit_type TEXT, ref_type TEXT, ref_id TEXT,

  meta_jsonb JSONB, graph_synced BOOLEAN DEFAULT FALSE);
CREATE INDEX idx_cu_hnsw ON content_unit USING hnsw (embedding vector_cosine_ops);
CREATE INDEX idx_cu_tsv  ON content_unit USING gin (search_tsv);
