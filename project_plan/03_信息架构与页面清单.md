# 03 · 信息架构与页面清单

## 1. 一级导航（8 项）

```
首页 · 书架 · 典籍 · 检索 · 练习 · 图谱 · 智能问答 · 我的
```

> 「书架」= 语料库**管理页**（浏览 / 导入 / 状态）；顶部**书籍切换器** = 全局**快速切**"当前语料"，影响检索 / 练习 / 图谱的默认范围。二者分工不重叠（**管理 vs 切换**）。见 [14 插拔式书籍扩展方案](14_插拔式书籍扩展方案.md)。

辅助入口：科研（`/research`，科研角色可见）、治理（`/admin`，管理员可见）、登录/注册。

## 3. 导航关系图

```
                         ┌──────── 顶部导航（全局） ────────┐
   首页 ──┬── 书架 ── (多语料) ── 进入语料 ── 典籍
          ├── 典籍 ── 目录树 ── 方剂详情 ─┬─ 条文详情
          │                              ├─ 案例详情 ─┬─ 讨论区
          │                              └─ 方心子图 ── 图谱探索 ── 相似度地图
          ├── 检索 ── 结果分面 ── (方剂/案例/条文详情)
          ├── 练习 ── 答题面板 ── 评分报告 ── 错题本
          │        └─ 案例盲盒 / 背诵打卡
          ├── 图谱 ── 图谱探索 / 方心子图 / 相似度地图
          ├── 智能问答 ── 会话历史
          └── 我的 ─┬─ 总览 / 档案 / 收藏 / 笔记 / 错题 / 方证库 / 路径
```

## 4. 主流程跳转（原型要跑通的路径）

```
首页 → 书架 → 切换语料 → 典籍 → 目录树 → 方剂详情 → 条文详情
首页 → 检索工作台 → 结果分面 → 方剂详情 → 条文详情
                                     └→ 图谱探索 → 相似度地图
首页 → 智能问答（工具轨迹 + 引用卡 → 跳原文）
首页 → 练习台 → 答题面板 → 评分报告 → 错题本
首页 → 我的 → 学习档案（雷达）
```

## 6. 响应式与多端

- 主战场：**桌面 Web**（三栏阅读、全屏图谱）。
- 适配：平板可读（图谱可触控缩放）；移动端本期以"能查能读"为最低目标，图谱/练习为轻量版。
