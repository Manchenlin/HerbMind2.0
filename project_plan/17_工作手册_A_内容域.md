## 7. 你的坑（本域专属）

1. **pg_jieba 没装** → 走 `jiebacfg (COPY=simple)` 兜底：能建表、能查询，但**中文不分词**（`麻黄汤` 命中 0）。装了才有分词效果（见 `database/pg/00-extensions.sql` 注释）。
2. **生成列 `search_tsv` 别映射到实体** → 插入会报错。
3. **时间用 `OffsetDateTime`**（不是 `LocalDateTime`），否则差 8 小时。
4. JSON 输出用 **camelCase**（`nodeType`），DB 列是 snake_case。
5. 目录**唯一表 `book_node`**——**没有** `book_chapter/section/category`，别去找。

## 8. ★ 前端页面：必须照原型做

**唯一视觉标准 = `project_plan/prototype/`**。你负责的页面都有对应原型：

| 你的页面 | 照这个原型 |
|---|---|
| 首页 | `prototype/index.html` |
| 书架 / 导入语料 | `prototype/shelf.html` / `import.html` |
| 典籍 / 目录节点 | `prototype/library.html` |
| 方剂 / 案例 / 条文 | `prototype/formula.html` / `case.html` / `quote.html` |
| 检索 / 结果 | `prototype/search.html` / `search-result.html` |
| 科研 | `prototype/graph-map.html` |

**做法**：① 样式**只用** `frontend/src/styles/theme.css` 已有的 class（**不另起颜色/间距**、**不引入 Element Plus**）；② 顶栏/页脚已实现（`AppHeader` + `footer`）直接用；③ 未实现页面在路由里是**占位页**，会自动告诉你"照哪个原型做"，换成真实组件即完成；④ 数据走 `/api/biz/**`。

> **照着抄就行**：`frontend/src/views/LibraryView.vue`（典籍页）就是照 `library.html` 做的范例。
