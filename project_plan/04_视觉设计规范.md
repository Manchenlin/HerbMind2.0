# 04 · 视觉设计规范

> 基调：**现代极简**（浅色、卡片化、大留白、克制）+ **有趣但不浮夸的微交互与页面转场**。
> 中医文化只做"轻点缀"（一处点睛色、一枚印章式 logo、书法体标题），不搞厚重古风。

## 1. 设计原则

1. **内容优先**：方证原文是主角，留白足够，减少装饰噪声。
2. **一次一处点睛**：朱砂色只用于关键操作/强调，不铺满屏幕。
3. **动效有意义**：每个动画都解释"发生了什么"（进入、切换、揭晓、加载），不做无意义炫技。
4. **快**：交互反馈 ≤ 100ms 出现，转场 ≤ 300ms 完成。

## 2. 配色 Token

| 角色 | 亮色 | 用途 |
|---|---|---|
| `--primary` 青木绿 | `#2E7D6F` | 主按钮、链接、选中态 |
| `--primary-deep` | `#1F5C52` | 悬停/按下 |
| `--primary-soft` | `#E6F2EF` | 选中背景、标签底 |
| `--accent` 赭朱 | `#D9724E` | 强调、必填、重要数字 |
| `--gold` 点睛金 | `#C8A96A` | 印章点缀、徽标描边 |
| `--bg` 暖白 | `#FAFAF8` | 页面背景 |
| `--surface` | `#FFFFFF` | 卡片/面板 |
| `--border` | `#ECECE8` | 分割线/描边 |
| `--text` | `#1F2328` | 正文 |
| `--text-2` | `#6B7280` | 次要文字 |
| `--success` | `#2E9E6B` | 命中/正确 |
| `--warning` | `#D9A441` | 遗漏/警告 |
| `--error` | `#C0453A` | 多余/错误 |
| `--info` | `#3B7DD8` | 提示 |

语义色（练习评分专用）：命中 **绿**、遗漏 **黄**、多余 **红** —— 与"证/方/治"高亮对应。

**深色模式**（可选）：`--bg #12161B`、`--surface #1B2027`、`--text #E8EAED`、主色提亮为 `#4FB3A3`，朱砂提亮为 `#E58A69`。

## 3. 字体

| 用途 | 字体 | 说明 |
|---|---|---|
| 标题 / 方名 / 条文 | **Noto Serif SC**（思源宋体） | 古雅，作标题与原文区 |
| 正文 / UI | **Noto Sans SC**（思源黑体） | 易读，界面与长文 |
| 数字 / 代码 | JetBrains Mono / 系统等宽 | 剂量、页码、代码 |

字阶：`12 / 14 / 16 / 20 / 24 / 32 / 40`；行高正文 1.7、标题 1.3。

## 4. 布局与形状

| Token | 值 | 用途 |
|---|---|---|
| 间距基数 | `4px`，常用 `8/12/16/24/32/48` | |
| 圆角 | `--radius-sm 6px` / `--radius 10px` / `--radius-lg 16px` | 卡片 10，面板 16 |
| 阴影 | `--shadow-1 0 1px 2px rgba(0,0,0,.04)` / `--shadow-2 0 6px 20px rgba(0,0,0,.08)` | 静置 / 悬浮 |
| 最大内容宽 | `1200px`（阅读正文 `720px`） | |

## 5. 组件规范（要点）

- **按钮**：主按钮填充 `--primary`，次按钮描边，文字按钮无色；圆角 10px；hover 上浮 1px + 阴影。
- **卡片**：白底 + `--border` 描边 + 圆角 10 + hover 上浮 2px + `--shadow-2`。
- **标签 Chip**：方剂药味用"君臣佐使"色标（君=主色、臣=青、佐=灰蓝、使=金）。
- **导航**：顶部横向 7 项，选中项下方 2px 主色下划线（带滑动过渡）。
- **表格/列表**：斑马纹极浅，行 hover 高亮，操作列右对齐。
- **空态/加载**：统一插画 + 骨架屏（shimmer）。
- **引用卡**：经典名 + 页码 + 摘录，hover 右侧浮出"跳原文 ↗"。

## 6. 动效与转场规范（★ 本项目的"有趣"担当）

| 场景 | 动效 | 时长/曲线 |
|---|---|---|
| **页面转场** | 旧页淡出（opacity 1→0 + translateY 0→-8px）/ 新页淡入（opacity 0→1 + translateY 8px→0） | 220ms `cubic-bezier(.22,.61,.36,1)` |
| 顶部路由进度条 | 细高 2px 主色进度条从左滑到右 | 假进度 300ms + 收尾 |
| 卡片入场 | 列表项 stagger 依次淡入上移（间隔 40ms） | 260ms |
| 数字统计 | 数字从 0 **滚动到目标值**（count-up） | 800ms ease-out |
| 卡片 hover | 上浮 2px + 阴影加深 + 描边变主色 | 160ms |
| 图谱节点 hover | 节点放大 1.15 + 邻居高亮 + 非邻居降透明 | 180ms |
| 图谱力导布局 | 节点从中心"生长"散开（初始 opacity 0 → 1） | 600ms |
| **答题揭晓** | 遮罩从下向上擦除（clip-path reveal）露出原著答案；或卡片翻转 | 480ms |
| 评分报告 | 雷达图从中心绘制；命中项逐条高亮"打字机"式出现 | 500ms + 60ms/项 |
| 引用卡预览 | hover 120ms 后浮出页面缩略/摘录 | 120ms delay |
| 侧边抽屉 | 从右滑入 + 背景遮罩淡入 | 240ms |
| 主题切换 | 全站颜色平滑过渡 | 300ms |
| 骨架屏 | shimmer 扫光循环 | 1.2s loop |
| 成功/收藏 | 图标弹跳（scale 1→1.2→1）+ 轻粒子 | 320ms |

**红线**：尊重 `prefers-reduced-motion`（用户若关闭动效则全部降级为直接切换）；动画不得阻塞交互。

## 7. 关键页面布局要点

- **首页**：顶部 Hero（大标题口号 + 中央大号语义检索框 + 背景极淡的脉络纹理）；下接"数据概览条"（535 方证 · 228 方 · 3 经典，数字滚动）、"今日方证"卡片、"图谱缩略预览"、四大快捷入口。首屏干净，一屏内可完成"搜一下"。
- **方剂详情**：三栏——左"典籍目录树"、中"正文栏目（锚点导航 + 渐进揭示）"、右"关联侧栏（mini 图谱、相关案例、收藏/笔记/讨论）"。药味 chip 标君臣佐使。
- **知识图谱**：全屏浅色画布（深色模式下墨底）+ 力导向；顶部筛选器（节点类型/经典/度数）；点击节点右滑抽屉；"以某方为心"重布局。
- **Agent 问答**：左会话列表 / 中对话流（气泡 + **工具调用折叠卡**："查询 → 图谱 → 统计"轨迹）/ 右联动 mini 图谱与相关方证；答案下引用卡可跳原文。
- **练习/答题**：上方案例原文（渐变遮罩藏答案），下方答题卡；提交后**揭晓动画** → 评分报告用二维雷达 + 逐条命中高亮（绿/黄/红）。

## 8. 无障碍

- 正文对比度 ≥ 4.5:1；交互元素聚焦有清晰 focus ring。
- 所有图标按钮有 `aria-label`；键盘可完成主流程。
- 动效可关闭；颜色不作为唯一信息载体（命中/遗漏同时用图标+文字）。
