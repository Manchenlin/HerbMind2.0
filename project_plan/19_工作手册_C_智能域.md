## 8. 你的坑

1. **LLM 健壮性**：单次 30s 超时 / 重试 2 / 连败熔断 30s / token 上限 + 每日配额。
2. **评分 `temperature=0`**，药味/剂量用**规则**，别全交 LLM。
3. **记忆**：本地 `InMemorySaver`，**生产换 `AsyncPostgresSaver`**。
4. **RAG 检索面向 `content_unit`**（不是 `rag_chunk`，那是旧名）。
5. 工具**一期望 6 个**（工具越多 LLM 越容易选错）；二期补到 11。
