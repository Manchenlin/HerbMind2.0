# 01 · 产品定位与用户研究

## 1. 背景与机会

《中医经典方证案例研究》（陈宝国主编，江西科学技术出版社 2016）是一本以**经典原文 + 医案**讲透"方证"的教材。它把《伤寒论》《温病学》《金匮要略》的方证，按「章 → 节 → 类 → 方证单元」组织，每个单元配【提要】【原文回顾】【案例】【证治归纳】【注意事项】【问题】【问题解答】【讨论】。

但纸质书存在三个结构性痛点：

1. **线性阅读 ≠ 临床检索**：临床是"以症求方、以证索方"，书却只能顺着目录翻。
2. **被动灌输 ≠ 主动思维**：读者看到的是结论，缺"先想一遍"的练习过程。
3. **隐性经验 ≠ 显性规律**：方-证-药-症的对应关系散在字里行间，读者很难自己看出规律。

**机会**：把这本书从"纸质信息"升级为"可检索、可练习、可推理、可挖掘的知识底座"，用一个 Agent 驱动的平台承接。

## 2. 一句话定位与价值主张

> **一个可插拔的多语料中医知识平台（以《中医经典方证案例研究》为首个语料），用 LangChain 1.x Agent 驱动，做经方临床思维练习与科研挖掘。**

> **定位升级说明**（见 [14 插拔式书籍扩展方案](14_插拔式书籍扩展方案.md)）：平台**不止服务一本书**——架构采用"插拔式书籍"模型，后续可接入《伤寒论》原文、本草书、医案书等公版古籍；本书是**首个、也是深度做得最透的语料**（即 L0 护城河）。

三条价值主张：
- **对学习者**：把"读方证"变成"练方证"——先思后看、AI 评分、错题本、能力雷达。
- **对临床者**：以症求方、辨证教练、加减推演、剂量换算——床边即用。
- **对科研者**：知识图谱 + 用药规律 + 可复现研究包——从"读"延伸到"发现"。

## 3. 用户画像（6 类）

| 角色 | 画像 | 核心诉求 | 主场景 | 高频功能 |
|---|---|---|---|---|
| **学生**（本/硕/规培） | 备考经典、背方证 | 记得住、练得会 | 刷方证、默写条文 | 练习台、背诵打卡、错题本、学习路径 |
| **规培/青年医师** | 临床想不起证治 | 快速对症查方 | 门诊间隙查方 | 检索、Agent 问答、加减推演、剂量换算 |
| **教师** | 带教、组卷、讲评 | 组织教学、看学情 | 课堂出题、点评 | 教师工作台、案例盲盒、班级学情看板 |
| **科研者** | 找证治规律、写论文 | 数据可分析、可导出 | 统计、图谱探索 | 科研工作台、图谱、数据导出、研究包 |
| **自学者/爱好者** | 兴趣入门 | 看得懂、有趣 | 逛图谱、问 AI | 首页、Agent 问答、图谱游览、歌诀生成 |
| **内容治理员**（管理员） | 保数据质量 | 可复核、可追溯 | 校验、修错 | 治理后台、复核工单、OCR 疑点 |

## 4. 场景地图（用户旅程示例）

**场景 A｜"这个病人该用什么方？"（青年医师）**
输入症状「无汗而喘、脉浮紧」→ 语义检索命中"麻黄汤证" → 方剂详情看组成/主治/原典条文 → 一键问 Agent「若兼项背强几几如何加减」→ 加减推演给出葛根汤 → 跳图谱看"麻黄汤→葛根汤"派生路径 → 收藏到"我的方证库"。

**场景 B｜"我想检验自己会不会"（学生）**
练习台选"太阳伤寒类方证"→ 案例盲盒随机出题 → 看案例原文，自拟辨证与处方 → 提交 → 评分报告：证候命中 3/4、方剂药味重合 5/6 → 看原著按语 → 加入错题本 → 系统推荐"下一批薄弱方证"。

**场景 C｜"桂枝汤到底见于哪些经典？"（科研者）**
条文详情页看"条文反向索引"→ 发现该条文被 3 个方剂、12 个案例引用 → 图谱"跨经典对照"显示同一方在《伤寒》《金匮》的异同 → 导出研究包（数据快照 + 图表 + 方法说明）。

**场景 D｜"帮我讲讲桂枝汤"（爱好者）**
首页语义检索 → Agent 问答，展示工具调用轨迹（查方→查条文→查图谱）→ 引用卡可直接跳原文 → 右侧联动 mini 图谱 → 生成记忆歌诀。

## 5. 痛点 → 解决方案映射

| 纸质书痛点 | 平台解决方案 | 对应模块 |
|---|---|---|
| 线性目录、难检索 | 多维筛选 + 语义检索 + 反向索引 | M1 |
| 结论先行、没有思考 | 先思后看 + AI 评分 + 辨证教练 | M3 |
| 经验隐性、规律难见 | 知识图谱 + 用药统计 + 相似度地图 | M6 / M8 |
| 记忆困难 | 背诵打卡(SRS) + 歌诀生成 | M4 / M7 |
| 学完无反馈 | 学习档案 + 能力雷达 + 错题本 | M4 |
| 无处交流 | 讨论区 + 笔记共享 | M5 |

## 6. 竞品/同类简析

| 类型 | 代表 | 差异点（本项目优势） |
|---|---|---|
| 古籍全文数据库 | 中医古籍 App / 中华医典 | 只"读"，不"练"；无 Agent、无图谱、无评分 |
| 方剂查询工具 | 各类中药/方剂 App | 单表查询，无方证关联、无医案、无原典溯源 |
| 通用 AI 问答 | 通用大模型 | 无知识底座、会幻觉；本项目 RAG + 引用可溯源 |
| 题库/考试类 | 执业医师题库 | 只对错，不评"辨证过程"；无案例推演 |

**差异化**：唯一一个**以单本经典为底座、把"检索-练习-推理-挖掘"打通**、且用**真图谱 + 真 Agent** 的平台。

## 7. 北极星与成功指标（建议）

- **北极星指标**：周活跃学习行为数（答题 + 练习 + 问答 + 图谱交互）。
- 辅助指标：练习完成率、评分提升曲线、Agent 问答引用命中率、图谱人均交互节点数。
