# HerbMind（本草心智）· 项目计划书 · 总览

> 可插拔的多语料中医知识平台（首个语料：《中医经典方证案例研究》）· 全新重构规划
> 版本：v2.0（重构蓝图）｜ 状态：规划中（M0）

## 一句话定位

**HerbMind 是一个可插拔的多语料中医知识平台（以《中医经典方证案例研究》为首个语料）、由 LangChain 1.x 多工具 Agent 驱动的经方「方证检索 · 临床思维练习 · 科研挖掘」一体化平台——让方证知识可查、可练、可问、可推演、可看见。**

首页口号：**「一图见方证，一问解经义，一练成明医。」**

## 本次规划要解决的问题

| 现状痛点 | 重构目标 |
|---|---|
| 只有 4 类功能、7 个页面，属"演示级雏形" | 9 大功能模块、20+ 页面，产品级完整体验 |
| 页面朴素、不吸引人 | 现代极简视觉 + 有趣的转场与微交互 |
| 条文无独立详情、答题无评分、收藏笔记有写无读 | 内容闭环、学习闭环、社区闭环 |
| RAG 只是单轮问答，未用 LangChain | **LangChain 1.x 多工具 Agent** 作为智能中枢 |
| 证-方-症 关系只存表、前端无可视化 | **Neo4j 真实知识图谱** + 可交互可视化 |

## 技术栈一句话

前端 Vue3+TS + 后端 Spring Cloud 微服务 + Python FastAPI/LangChain 1.x Agent ，
数据用 PostgreSQL（向量+中文全文）与 Neo4j（知识图谱），Nacos 做注册中心；
LLM/Embedding 走硅基流动云端（本机无 GPU）。**开发期应用跑 IDE、中间件跑 Docker，部署由你定。**

## 术语表

| 术语 | 含义 |
|---|---|
| 方证 | 方剂与其对应的证候（症状/舌脉/治法）组合，本书的核心知识单元 |
| 方证单元 | 书中一个完整条目，含【提要】【原文回顾】【案例】【证治归纳】【问题】等栏目 |
| 先思后看 | 练习模式：先给案例原文，用户先辨证处方，再揭晓原著答案 |
| **练习（原「训练」）** | 指**用户练习 / 考核**（答题 → 评分），类比"刷题软件"；**不是**机器学习的"训练模型"。为免歧义，UI 文案统一用「练习」 |
| 模型训练 / 微调 | 用数据调整大模型参数 —— **本项目不涉及**；大模型仅经云 API 做**推理** |
| 语料（book） | 一部可插拔的书籍/资料（方证/本草/药品/医案）；用户也可自行导入（UGC，走审核） |
| Agent | 基于 LangChain 1.x 的多工具智能体，可查方、查图谱、评分、换算等 |
| RAG | 检索增强生成：先召回复原知识，再由 LLM 生成并附引用 |
| pgvector / pg_jieba | PostgreSQL 的向量检索扩展 / 中文分词全文检索扩展 |
| BFF | Backend For Frontend，面向页面的聚合编排层 |
