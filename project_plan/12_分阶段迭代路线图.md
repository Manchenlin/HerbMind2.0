# 12 · 分阶段迭代路线图

> 原则：**先数据、后骨架、再智能**；每个里程碑可独立验收。开发期一律「应用跑 IDE、中间件跑 Docker」，部署决策留到 M8。

## 里程碑总览

| 阶段 | 名称 | 目标 | 验收标准 |
|---|---|---|---|
| **M0** | 蓝图与原型 | 定方向，可点击看效果 | `project_plan/` 文档全集 + HTML 原型跑通主流程；评审通过 |
| **M1** | 数据底座重构 | 数据正确、可检索、可建图、**可扩展** | PG 表 v2（含 book/book_node/content_unit）建好；535 条全入；Neo4j 节点/关系数达标；向量召回抽检合格 |
| **M2** | 骨架与首页 | 能跑能看 | Gateway+BFF+identity+catalog+search 起；前端框架 + 首页；BFF 聚合接口通 |
| **M3** | 内容阅读 | 内容闭环 | 典籍浏览、方剂/案例/条文详情、收藏笔记可用 |
| **M4** | 练习与档案 | 学习闭环 | 练习台 + 自动评分（证/方/治分项）+ 个人中心/雷达/错题本 |
| **M5** | 知识图谱 | 可视化 | `/graph` 力导向可交互；`/graph/map` 相似度地图出图 |
| **M6** | Agent 服务 | 智能化 | `create_agent` + **一期 6 工具**（二期补至 11）+ 记忆 + 引用；工具轨迹可视；引用可跳原文 |
| **M7** | 创新功能 | 亮点 | 盲盒、加减推演、背诵打卡、学习路径、辨证教练端到端可用 |
| **M8** | 治理与上线 | 运营就绪 | 治理工单闭环；科研导出；Docker 全栈一键部署；Tracing 可观测 |

## 依赖关系

```
M0 ─▶ M1 ─▶ M2 ─▶ M3 ─▶ M4 ─┐
                     │        ├─▶ M6 ─▶ M7 ─▶ M8
```

## 各阶段任务分解

### M1 数据底座重构
- 建 PG 表 v2（内容域增强 + 练习/学习/图谱/Agent 域新增）。
- **落地可扩展数据模型**：`book`（语料）+ `book_node`（通用目录骨架）+ `content_unit`（统一，原 `rag_chunk` 升级）；ETL 泛化为"通用古籍导入器"（栏目规则模板 + 字段→本体映射）。见 [14](14_插拔式书籍扩展方案.md)。
- 重跑 ETL：docx → CSV → PG；补 `efficacy`、药味结构化、异体字归一。
- `content_unit` v2（原 `rag_chunk` 升级）：加 `unit_type`、`search_tsv`、重新向量化。
- 建 Neo4j：约束 + 节点/关系批量导入 + `graph_synced` 回写。
- 治理：把已知残留项（各等分/异体字/粘连）录入 `issue`。

### M2 骨架与首页
- 后端：Gateway（JWT/路由/限流）、BFF（home 聚合）、identity、catalog、search 五个服务跑通。
- 前端：Vite + 路由 + 全局布局 + 首页（Hero 检索 + 概览 + 今日方证）。

### M3 内容阅读
- 典籍目录树、方剂详情（君臣佐使）、案例详情（栏目折叠）、**条文详情（新增）**。
- 收藏/笔记打通读写；讨论区基础版。

### M4 练习与档案
- 练习台 + 答题面板 + **自动评分**（Agent `syndrome_score` + 药味 F1）。
- 个人中心：总览、能力雷达、错题本、我的方证库。

### M5 知识图谱
- `svc-graph` 查询接口 + 前端力导向图 + 方心子图。
- 相似度地图（UMAP 降维 + 前端渲染）。

### M6 Agent 服务
- `herbmind-agent`：`create_agent` + **一期 6 工具**（二期补至 11）+ 记忆 + 结构化输出。
- RAG 管线（混合召回 + Reranker）、SSE 流式、工具轨迹可视化、Tracing。

### M7 创新功能
- 案例盲盒、方剂加减推演、剂量换算器、条文背诵打卡(SRS)、学习路径、辨证教练。

### M8 治理与上线
- 治理后台工单流、审计；科研工作台 + 导出 + 可复现研究包。
- `docker/` 全栈 compose；Actuator + LangSmith 监控。
- **部署决策**：由用户决定是否上 Docker / 虚拟机。

## 建议节奏

- 以"**每周一个可演示增量**"推进；M0 先行（本次），M1 为后续一切前提。
