## 2. 三步跑起来

在**代码根目录**（能看到 `docker/`、`backend/`、`frontend/` 的那一层）打开终端（Git Bash）：

### 第 1 步：起中间件（第一次会下载镜像，约 5–10 分钟）

```bash
docker compose -f docker/docker-compose.infra.yml up -d
```

看看是否成功：

```bash
docker ps
```

**应该看到 4 个容器**：`herbmind-v2-pg`、`herbmind-v2-neo4j`、`herbmind-v2-redis`、`herbmind-v2-nacos`。
（第一次要多等一会儿，等到都显示 `(healthy)`。）

> ✅ 表结构**不用你管**——容器第一次启动时会自动建好 41 张表。

### 第 2 步：导入数据快照

**先装一次 Python 依赖**（脚本最后一步要建图，缺依赖会报 `No module named 'neo4j'`）：

```bash
pip install -r database/etl/requirements.txt
```

`herbmind_data.sql.gz` 由组长发给你，放到任意位置（比如桌面），然后：

```bash
bash scripts/init-data.sh /c/Users/你的用户名/Desktop/herbmind_data.sql.gz
```

> 路径写法：Windows 的 `C:\Users\me\Desktop\x.gz` 在 Git Bash 里要写成 `/c/Users/me/Desktop/x.gz`。

**成功的标志**（会打印）：

```
formula=245  case_record=290  classic_quote=568  content_unit=535  向量=535
build_graph: ok (Formula=245, Herb=363, COMPOSED_OF=979)
完成 ✅
```

### 第 3 步：起服务

**后端**（推荐用 IDEA 打开 `backend/pom.xml`，等它加载完 Maven，再依次启动这三个类）：

| 顺序 | 类 | 端口 |
|---|---|---|
| 1 | `CatalogApplication` | 8082 |
| 2 | `BffApplication` | 8090 |
| 3 | `GatewayApplication` | 8080 |

或者用脚本一键起：`bash scripts/run-dev.sh`

**前端**：

```bash
cd frontend
npm install     # 第一次要几分钟
npm run dev
```

浏览器打开 **http://localhost:5173/library** —— 能看到「典籍浏览」和左边目录树就成功了 🎉

## 4. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 服务启动后端口是 `61099` 之类的怪数字，或报 `Port xxx already in use` | 你的环境变量里有 `SERVER_PORT`/`SERVER__PORT` 覆盖了配置。启动命令加 `--server.port=8082`；或先 `unset SERVER_PORT SERVER__PORT`（`scripts/run-dev.sh` 已处理） |
| `docker compose up` 报容器名已存在 | 你本机有别的项目也用 Docker。本项目容器都叫 `herbmind-v2-*`，不会冲突；若真冲突，`docker compose -f docker/docker-compose.infra.yml down` 再来 |
| `init-data.sh` 报 `gunzip: command not found` | 用 Git Bash 而不是 CMD/PowerShell |
| 导入后页面还是空的 | 检查第 2 步的计数是否打印出 `245 / 290 / 568 / 535`；没有就是快照没导进去 |
| `mvn` 命令报 `ClassNotFoundException ... classworlds.launcher.Launcher` | 本机 Maven 装坏了。**用 IDEA 内置的 Maven** 即可，或让组长帮你配一个可用的 Maven |
| 前端 `npm install` 很慢/失败 | 换国内镜像：`npm config set registry https://registry.npmmirror.com` |
| 改完代码要重新导入数据吗？ | **不要**。只有表结构变了才需要；日常改代码不用动数据库 |
| 我把数据搞乱了想重来 | 再跑一次 `bash scripts/init-data.sh <快照>` 即可（脚本带 `--clean`，会重建数据） |

> ⚠️ **别做的事**：不要 `docker compose down -v`（会删掉数据卷，数据全没，得重新导入）；不要把 `herbmind_data.sql.gz` 提交到 Git（已在 `.gitignore` 里挡着）。
